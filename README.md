# FitCoach 
**Персональний AI Фітнес-Тренер на базі LangChain та OpenAI**

FitCoach - це інтелектуальний асистент, розроблений для допомоги користувачам у плануванні тренувань та розрахунку ключових показників здоров'я. Проєкт реалізовано з використанням архітектури **Tool-calling Agent**, де нейромережа виступає в ролі маршрутизатора, а всі точні розрахунки виконуються через спеціалізовані Python-інструменти.

##  Основний функціонал (Інструменти)

Система використовує 4 інтегровані інструменти (Tools):
*    **bmi_calculator:** Точний розрахунок індексу маси тіла (ІМТ) та надання базових рекомендацій щодо ваги.
*    **calorie_calculator:** Розрахунок базового метаболізму (BMR) та денної норми калорій (TDEE) за формулою Міффліна-Сан Жеора для різних цілей (схуднення, підтримка, набір маси).
*    **exercise_lookup:** Розумний пошук вправ для 6 груп м'язів з адаптацією під локацію (вдома / в тренажерному залі) та рівень складності.
*    **workout_timer:** Генерація планів для інтервальних тренувань (Табата, HIIT) на заданий користувачем час.

## 🛠 Технологічний стек
*   **Оркестрація:** LangChain, LangGraph
*   **LLM:** OpenAI `gpt-4o-mini` (оптимізовано для швидкого виклику інструментів та мінімальної вартості)
*   **Мова програмування:** Python 3.x
*   **Середовище:** Google Colab / Jupyter Notebook

## 🛡 Архітектурні рішення та Безпека
1.  **Уникнення галюцинацій:** Математичні формули винесені з LLM у жорсткий код інструментів. Модель лише витягує параметри з тексту та передає їх у функції, що гарантує 100% точність розрахунків.
2.  **Утримання контексту (State Management):** Система зберігає історію повідомлень поточної сесії, запам'ятовуючи вагу, зріст та вік користувача для наступних питань.
3.  **Guardrails (Захист):** На рівні системного промпта встановлено жорсткі обмеження — агент відмовляється надавати медичні поради чи призначати ліки, залишаючись виключно в рамках фітнес-експертизи.
